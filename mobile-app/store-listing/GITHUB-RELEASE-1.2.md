## Hadirku Lecarassa 1.2

Aplikasi absensi dan administrasi HR untuk karyawan, HOD, HRD, dan Admin Lecarassa.

### Yang baru di 1.2

- Modul admin/HOD lengkap: persetujuan, jadwal, karyawan, laporan, klaim makan, training, master data, dan pengaturan.
- Penggajian mobile: periode bulanan, penyesuaian gaji, finalisasi, pembayaran, gaji harian, export, dan riwayat.
- Peningkatan performa: layar admin dimuat terpisah agar startup lebih ringan.
- Perbaikan laporan bulanan untuk bulan dengan 30 hari.

### Cara install

1. Unduh APK.
2. Buka file APK di HP Android.
3. Jika diminta, aktifkan **Install unknown apps** untuk browser/file manager.
4. Install, lalu izinkan kamera dan lokasi saat pertama membuka aplikasi.

APK ini ditandatangani dengan release key resmi. Jangan install APK dari sumber
lain. Untuk update, install versi baru di atas aplikasi lama; jangan uninstall
agar data tetap tersimpan.
